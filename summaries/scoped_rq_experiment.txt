scoped_rq_experiment (2026-07-24)

IDEA / PARAMETERS: This was the first real, GPU-executed test of the project's core research question - whether fairer (less disparate) retrieval rankings come at a cost to, or can even improve, downstream RAG generation quality - after this session's methodological cleanup of the codebase (shared analysis/ package, notebook architecture split, fixed metric/label duplication). Scope was deliberately narrowed to fit one laptop's GPU in a reasonable time rather than attempting the paper's full grid: retriever=BM25 only (SPLADE/Contriever retrieval was never precomputed), generator=flanT5Small only, all 7 LaMP tasks, num_queries=100 per task (51 for LaMP-1, which has a smaller corpus), seed=42, four rerank settings per task - deterministic (EE-D baseline), MMR (lambda=0.55), and Plackett-Luce sampling at alpha=2 and alpha=8 with 10 stochastic samples per query (pl_samples=10). 28 total settings, 2,604 (qid, list_id) generation units, produced via experiments/scoped_experiment.py (batch_id=scoped_rq_experiment, reuse_policy=smart). Total wall-clock time: 5,856s (97.6 minutes), measured directly from each run's manifest.json started_at/updated_at timestamps.

RESULTS / CONCLUSIONS: Three findings came out of this run. (1) Structural: EE-D disparity can never drop below 1.0 for deterministic or MMR, since both produce exactly one ranked list per query and the EE-D metric is only meaningful across multiple sampled rankings for the same query - MMR is therefore not a fairness intervention in this paper's sense, just an unrelated diversity-based reranker riding the same utility axis. (2) Paper comparison: after fixing a real bug in analysis/binning.py (pool_delta_by_bin was binning the deterministic baseline too, which is wrong since a single-list baseline only ever has one EE-D value - fixed via a new bin_baseline=False mode matching the paper's Table 2 methodology exactly), the paper-style delta-by-EE-D-bin table qualitatively replicates the paper's own pattern (utility recovers or improves as EE-D climbs into [0.6,1.0), worst in [0.0,0.4)) - but several bins have as few as 2-7 comparison queries, since only 2 of the paper's 4 alpha values were run, so this should be read as directional, not statistically powered. (3) Mediation test: EU~EE-D alone is not significant (p=0.53), but adding ILD to the regression shrinks EE-D's coefficient by 62% while ILD itself is significant (p=0.0001, negative sign - higher diversity associated with lower utility in this data) - suggestive of diversity, not disparity per se, driving utility differences, though R^2=0.007 means this should not be over-interpreted. Full detail in docs/PROJECT_STATUS.md section 7. Follow-up: docs/PROJECT_STATUS.md section 7's next-steps list identified the alpha-sweep gap and (after re-reading the paper's methodology more closely) an N=10-vs-paper's-N=100 sampling-size gap as the two highest-value fixes, addressed by the pl_alpha_sweep_n30 experiment (see summaries/pl_alpha_sweep_n30.txt).
