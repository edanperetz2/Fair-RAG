# docs/

- **`PROJECT_STATUS.md`** — full project history/handoff: what was tried, by whom, what's
  abandoned vs. active, and recommended next steps for the actual research question.
  Start here if you're new to the project or picking it back up after a break.
- **`project_proposal.pdf`** — the original project proposal (Idan Peretz & Avi Simkin),
  defining the research question this project answers.
- **`fair_rag_paper.pdf`** — the paper this repo's code is based on/extends
  ("Towards Fair RAG: On the Impact of Fair Ranking in Retrieval-Augmented Generation").

The finished output of this project is **`report/latex/main.pdf`** (source:
`report/latex/main.tex`) — the answer to the research question above, not a document
in this folder.

For how to actually run the code, see `README.md` at the repo root. For code
architecture, see `CLAUDE.md` at the repo root.
